# CampusFind

Smart Lost-and-Found Matching and Recovery Management System. The existing application scaffold and implementation are in [`CampusFind_Project_Structure/`](CampusFind_Project_Structure/README.md).

Stack: React + Vite, FastAPI, SQLAlchemy/Alembic, and PostgreSQL. See the nested README for Docker-based setup and deployment steps, and `CampusFind_Project_Structure/TRACEABILITY.md` for the supplied UML workflow mapping and remaining verification limits.
